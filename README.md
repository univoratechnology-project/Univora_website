# Univora React Website

Modern dark IT-company landing page inspired by the provided Univora design.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Stack

- React
- Vite
- Framer Motion
- Lucide React
- Responsive CSS
- Animated/glowing background effects

Replace the Unsplash image URLs in `src/App.jsx` with your own company images when ready.
